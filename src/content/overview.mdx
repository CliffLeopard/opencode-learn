## 四条约束

这四条在后面的正文里不再换说法。

- **shape 只定义一次。** 对外 shape 在 `packages/schema` 和 `packages/protocol`。`packages/core` 不重新发明一套事件或 HTTP shape。
- **依赖往下走。** `AGENTS.md` 规定运行时依赖从 Schema 到 Core 和 Protocol，再从 Core 和 Protocol 到 Server。Client 可以依赖 Schema 和 Protocol，不依赖 Core 或 Server。`sdk` 在进程内同时组成 Client、Core 和 Server。
- **一步是一次模型调用。** 一步的持久记录只覆盖模型看得见的那一段。
- **先记下不可再推导的事实。** 持久事件只记录不能从有序历史折出来的新事实。
